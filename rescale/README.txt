This is a rescale patch meant for (you guessed it) RSS Adapter
It rescales parts phyiscally by 1.6x but does not change fuel, thrust, etc. values as the base parts are technically scaled around 1.6x already.
Ideally, the gameplay will still be the same with the change that things just have realistic sizes.

It requires Harmony as an extra dependency to patch a FreeIVA bug
