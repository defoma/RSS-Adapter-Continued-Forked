These are the optional extras folder, which are configs that are disabled by default but can be enabled by removing the ".ban" at the end of the file
Included:


RealIonThrust.cfg: One of the few things I intentionally left "unrealistic" was the ion engines thrust, to make it usable without the need of Background or Persistant thrust. Enabling this patch lowers the thrust by several orders of magnitude, to match with real world ion engine values. If you do enable this, either get the Background/Persistant thrust mod or sit very very patiently at your computer.

RealFarFutureThrust.cfg: Pretty much the same situation as the ion thrust config. A few of the engines would have really low thrust IRL which would make it borderline unplayable without other mods.

RealSupplimentaryEEThrust.cfg: Same as the other two, except some of the engines come with internal ceasium fuel if enabled, to match real world fuel loads.

RealNames.cfg: (enabled by default) Switches on the real world part names and descriptions. The names themselves are real_title / real_description keys in each Support patch (same as BDB), and this file applies them, ORANGES' own real names included. Disable it by renaming the file to "RealName.txt" or really anything that isn't a .cfg

HideStockVolumeTanks.cfg: (enabled by default) Hides BDB's "stock volume" options on the Able/Delta upper-stage tank. They carry about twice the real propellant, so at real scale only the real-volume Able and Delta options are kept. Disable it by renaming the file to anything that isn't a .cfg

SolRealDSN.cfg: For Sol (Sol-Configs) at Real scale with LRTR. LRTR only uses its real-size DSN ranges (100x stronger) with the RSS mod, so with Sol you get the stock-size ones and interplanetary antennas cannot reach Venus until a high tracking station level. Enabling this applies the real-size ranges with Sol too. Only for Sol on Real scale.
